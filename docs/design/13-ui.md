# 13 — UI (short)

## 1. Purpose and scope
Two different things:
1. **Developer UI:** the console, overlays, dev tools and the editor.
2. **Game UI:** HUD, menus, inventory, dialogue.

They use different technology on purpose. Expanded before inventory/dialogue screens are built.

## 3. Key decisions
- **Developer UI = Dear ImGui**, via the already vendored `packages/MonoGame.ImGuiNet-main` (today's `Game1.GuiRenderer`).
  - It's used for the console (02 §4.2), `stat` overlays, dev windows and the whole editor (15).
  - Drawn in the Overlay pass (06).
  - Compiled only into dev builds and the editor host. **Not in `Shipping`.**
  - The **console** is the exception: v1 uses an ImGui window (dev builds). The `Shipping` console (`con_enable`, 01 §3.2) is a simple drop-down drawn with the game UI's font renderer, built with the game UI (D8).
- **Game UI = to be decided (ARCHITECTURE D8).** The candidates to evaluate are **Gum** and **Myra** (both MonoGame UI libraries), against a small custom retained UI. Criteria:
  - gamepad and keyboard navigation;
  - data-driven layouts (moddable, hot-reloadable);
  - text rendering with Unicode, localization keys (05) and runtime TTF fonts;
  - resolution scaling;
  - allocation behaviour;
  - licence.
- **Fonts:** runtime TTF rendering (e.g. FontStashSharp **[candidate, unverified]**) rather than MGCB `SpriteFont`s, since MGCB is no longer part of the pipeline (05).
- **v1 HUD before the decision:** a minimal immediate-mode HUD with `SpriteBatch` in the Overlay pass: health, crosshair, interaction prompt, and a pickup message.
- **Input** for UI goes through the `UI` context (08 §3.3), and text through `Window.TextInput` (08 §3.5).
- **UI reads simulation state; it never writes it.** Buttons that do something in the game ("use item") send commands through the input/command path (04 §3.1 rule), never direct component writes.

## 4. API sketch
```csharp
public sealed class DevUi                           // client module service (ImGui); dev builds and editor host only
{
    public void AddWindow(string menuPath, Action draw);   // e.g. "Debug/Physics"
    public bool WantsMouse { get; }  public bool WantsKeyboard { get; }   // feeds the UI input context (08)
}

public sealed class Hud                             // v1 immediate-mode HUD (SpriteBatch, Overlay pass)
{
    public void Bar(Vector2 pos, Vector2 size, float fraction, Rgba color);
    public void Text(Vector2 pos, string localizationKeyOrText, Rgba color);
    public void Icon(Vector2 pos, AssetPath texture);
}
```

## 11. v1 scope vs later
- **v1:** the ImGui console + `stat` overlays (**built in migration step 2**; until the game UI exists, a Shipping build with `con_enable 1` reuses the ImGui console window); the immediate-mode HUD; log category `UI`.
- **Later:** evaluate Gum/Myra vs custom (D8); menus, inventory, dialogue, options (with rebinding, 08); localization switching.
