## 2. Decisions the owner made (they shape everything after)

- **Base engine first**, genre-agnostic, with genre code in kits (REDESIGN §0.5).
- **3D and 2D, both first-class**: one engine, two spatial profiles; a physics facade now, a real 2D
  backend (Aether.Physics2D first candidate) later.
- **Action RPGs are the first target family** — Daggerfall, Half-Life, Morrowind, S.T.A.L.K.E.R. — then
  other genres (Stage D), then designer tools, full modding and the editor (Stage E).
- **MIT licence.**
- **Green PRs are merged** as they go (the owner asked for it). One branch and one PR per issue.

Still open (REDESIGN §6): scripting (typed conditions/actions first, a language only on evidence), editor
technology, whether modders get the editor, wrapping Friflo, target platforms, distribution.

## 3. How to build, test and verify now

```bash
dotnet tool restore
dotnet build Sage.sln -c Debug                              # needs the .NET 10 SDK (global.json)
dotnet build Sage.sln -c Debug -p:SageSkipShaders=true      # on Linux: mgfxc needs Wine, so skip shaders
dotnet test tests/Sage.Tests -c Debug                       # and -c Development; not Shipping (6 dev-only tests)
python3 tools/check_docs.py --tests <count>                 # --fix rewrites the quoted counts
tools/smoke_run.sh src/Sage.Host/bin/Development/net8.0 games/Sandbox 3 Shaders Audio   # the real game, under Xvfb
```

- **The .NET 10 SDK builds; the .NET 8 runtime runs.** The 8.0.1xx compiler emitted code the runtime
  rejected (`InvalidProgramException` in `Assert.Fail`). Have the .NET 8 runtime installed too: with only a
  newer runtime, `RollForward=Major` hides .NET 8 bugs (that is how every save failing went unnoticed).
- **Warnings are errors.** Suppress only with a scoped `#pragma` and a reason.
- **Tests run in parallel.** A test that changes process-wide state on purpose goes in
  `[Collection(ProcessWideStateCollection.Name)]`; one that measures time or allocation in
  `[Collection(MeasurementsCollection.Name)]` (`tests/Sage.Tests/Core/TestSupport.cs`).
- **The smoke run is the only check of the client** — tests cannot reference `Sage.Client` by design. Run
  it after touching boot, the client or the host. It fails on a crash, a bad exit, a missing shutdown line
  or any WARN/ERROR outside the categories you allow.
- **CI** (`.github/workflows/ci.yml`): Linux builds the solution in all three configurations (host without
  shaders), tests in Debug and Development on .NET 8, runs `check_docs` with the real count and smoke-runs
  both games; Windows builds everything with shaders and runs the tests.

## 5. Traps this session hit (so the next one doesn't)

- **`git clean -fdx` deletes new, untracked files** — including the ones you just wrote. Clean build output
  with `find . \( -name bin -o -name obj \) -type d -prune -exec rm -rf {} +` instead.
- **This clone is shallow and tracks only `main`.** Fetch other branches with an explicit refspec:
  `git fetch origin +refs/heads/<b>:refs/remotes/origin/<b>`.
- **A green CI run tested the PR against the `main` it branched from.** When two PRs land close together,
  merge `main` into the second (or test the combination locally) before merging it.
- **`check_docs` counts tests.** Adding tests means `--fix` for the quoted counts, or CI's docs step fails
  (it did, once, on #36).
- **Fixed-step arithmetic:** sixty 1/60 s steps sum to just under 1.0 s, and `maxFrameTime` clamps; a test
  that wants N ticks passes a hair more than N/rate and a cap above it.
- **Register in `Init`.** It is now enforced — a late cvar, record type, action, part or module throws — and
  the first thing the seal caught was the renderer registering `r_fog` in its constructor, after
  `config.cfg`.
- **Friflo pulls in LGPL-3.0 assemblies.** A shipped game must include `THIRD_PARTY_NOTICES.md`.
