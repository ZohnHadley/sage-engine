  closed); a later sample pass can give them schedules.
- **A Development host doesn't compile a mod's shaders on load** (#590): `asset_hotreload` defaults to on only with

## 5. Traps

- **A stacked PR closes when its base branch is deleted.** #589 (5-4, on 5-3's branch) was closed when 5-3 merged
  with `--delete-branch`, and had to be reopened as #594. Retarget the stacked PR to `main` first
  (`gh pr edit N --base main`), then delete the branch. After a squash merge, merging `main` into the stacked branch
  conflicts on the lines both touched: take the stacked side where it is the superset.
- **The Sandbox boots to its title screen.** A scripted run needs `-notitle` (`tools/smoke_run.sh` adds it);
  `time_set` and `warp` need `+sv_cheats 1`. A data-only game's smoke run allows `Shaders Audio Records Input`, as the
  other `tests/games/*` do; `Shaders` alone fails on the engine's UI records.
- **On-screen runs on Windows:** `Sage.Host.exe -game ../../../../../games/Sandbox -notitle "+vid_width 1280"
  "+vid_height 720" … "+wait 6" "+screenshot" "+quit"` from `src/Sage.Host/bin/Development/net8.0`, after a
  Development build *with* shaders (a `SageSkipShaders` build deletes the `.mgfxo`). Screenshots land in
  `user/sandbox/screenshots`.
- **`games` matches `tests/Sage.Tests/Games` on Windows** (case-insensitive): find the repository root by
  `TestEnv.FolderAbove("engine_content")`, not `FolderAbove("games")`.
- **AI opens doors on its path** and **an AI without a faction takes the player for an enemy.** A door a sequence
  opens must start `locked`, and a friendly NPC needs a faction.
- **A follower is a `routine` anchored on the player**, as there is no follow task: `MoveToAnchor` within 2 m,
  `StayAt` failing past 3 m. Give a headless test room for a three-second pause before the walk.
- **Camera views resolve in a frame.** A headless test that reads `MainViewRig` must also `RunFrame`, not only
  `RunFixed`.
- **`dotnet new` templates from a sample folder:** NuGet appends a file's own folder to a folder-style `PackagePath`,
  so the samples' `Content` takes `PackagePath="content/"`, not `content/%(RecursiveDir)`. Try a template in a
  throwaway hive (`--debug:custom-hive`) so the owner's own `dotnet new` list is untouched.
