## 5. Traps

- **Background GC breaks per-thread allocation readings** (#81, see the 09-29 handoff §5):
  `Sage.Tests.csproj` sets `ConcurrentGarbageCollection=false`, and `AllocationProbe.Measure` refuses to
  run without it. `sage.physics.step` allocates 40 B a tick: disable it in zero-allocation tests.
- **The log folds repeats, from whichever thread drains it.** Anything that collects log entries per
  thread (validation, tests) must ignore the "(previous message repeated …)" note or it depends on timing
  (#110, #111).
- **Parallel agents sharing one machine:** serialise heavy commands with a lock, and never let MSBuild's
  reused worker nodes or the compiler server inherit the lock's file descriptor — they outlive the build
  and hold the lock forever. Use `MSBUILDDISABLENODEREUSE=1 flock -o <lock> <cmd>` and
  `-nodeReuse:false`. With four agents building at once the container ran out of memory and restarted,
  more than once.
- **Merge order of parallel PRs:** every PR that adds tests changes the counts `check_docs` checks
  (README, ARCHITECTURE, a history handoff). Merge one PR, merge `main` into the next, take `main`'s
  side of the count lines, re-run the tests and `check_docs --fix` with the real count, then push.
- **The physics step allocates 40 B a tick** when a static collider exists (the backend, not ours). The
  4d allocation tests subtract it (see `FiftyNpcsAllocateNothingPerTick`); fix it or keep subtracting.
- **A pose is rewritten from scratch every tick** (even an LOD-skipped one) before IK runs, or IK
  compounds. Anything new that writes into `SkeletonPoses` must do the same.
- **A host build with `SageSkipShaders` deletes the Wine-compiled `.mgfxo`** in `bin/.../Content/shaders`:
  build the host last, with `MGFXC_WINE_PATH`, before taking screenshots.
- **One cloud session, several conversations.** `/clear` starts a new conversation in the same session; the
  old ones are not running, but GitHub events for PRs they subscribed to can wake whichever conversation is
  open. Check the transcripts in `~/.claude/projects/-home-user-HackTheHill/` (and `git reflog`) before
  assuming another agent is at work.
- **Screenshots on Linux** need shaders, and `mgfxc` needs Wine with a Windows .NET and a D3D compiler.
  This session assembled a prefix from NuGet packages (the download hosts were blocked) with a stub
  `fxccs.dll` that calls `D3DCompile`; build the host without `SageSkipShaders` and with
  `MGFXC_WINE_PATH`, then run with `"+vid_width 1280" "+vid_height 720" … "+screenshot 3"`. The prefix
  lives in the container, not the repository.
