## 2. In progress: #24, the assembly split

- **Branch `claude/p3-assembly-split`**, started from #63's branch; being implemented by an agent at the
  time of writing. If it has not been merged when you read this, check the branch and its PR first.
- **The plan:** [`plan-24-assembly-split.md`](plan-24-assembly-split.md) — every cycle the split would
  create and its fix, a file-by-file move map, generator and test changes, and the order.
- **Shape:** `Sage.Core ← Sage.Simulation ← Sage.Physics3D ← Sage.Gameplay`; `Sage.Client → Gameplay`.
  `Engine`, `World` and `SageApp` sit in Simulation (a deliberate deviation from REDESIGN §3.1, which put
  the kernel in Core: `World` and `IModule.OnWorldCreated(World)` make them inseparable). The character
  controller goes to Physics3D; `PawnIntent` to Simulation; a minimal `IPhysicsWorld` seeds #30; no kit
  projects yet (the kit screens park in `Sage.Gameplay/Rpg/` for #27); plugin ids unchanged;
  `SageAppOptions.IncludeSimulationModules` becomes `AvailablePlugins = BasePlugins.All()`.
- **One PR, four commits, each green:** decouple inside `Sage.Engine`; split with the namespace still
  `sage_engine`; rename to `Sage.*`; the SAGE0025 "a base assembly references a kit" analyzer, guard tests
  and docs. A baseline (registry dump, `sage validate`, `sage schema`, the ECS schema line) is taken
  first and must match after each commit.
- **While it is open, don't start other Phase 3 work in `src/Sage.Engine`**: it moves nearly every file.
