## 2. Known limits and what is not verified

- **`ATenThousandEntityAutosaveCostsTheTickUnderAFrame` asserts wall-clock time** (under 16.7 ms, about 6 ms
  locally), the suite's first such bound outside a ratio. It passed on CI's runners; a slower runner could make
  it flaky.
- **`Slots` shows a save before its files exist.** Code that opens a slot's files right after a background save
  must call `WaitForWrites()`; only tests did, and the kit's menus read `ThumbnailPath`, which stays null until the
  file is there.

- **A saved `r_instancing "0"` stands.** The cvar is archived, so a config written before #610 keeps instancing off,
  this clone's `user/rendercheck` among them.
- **The Sandbox's sword blade reads about 209 on `main` and #610, and about 241 on a host built at #630.** Not
  lamps, shadows or instancing (`r_lights 0`, `r_shadows 0` and `r_instancing 0` leave it). The cause was not found,
  and it may be that host's own settings.
- **Graphics gaps the showcase found** (PR #640's description, not yet issues; file them next): brush faces have
  no tangents, so normal maps do nothing on `.map` and `sage:brush` faces; data games have no on-screen message

  namespace; no data action sets weather, sky or hour without cheats; a scene can't name a calendar; `particles` is

## 4. Traps

- **Archived cvars persist, again.** A local render-check run that ends with `r_post 1` leaves the grey grade
  on for the next run, whose drawing check then fails grey. End a local run with `+r_post 0`, or reset
  `user/rendercheck/config.cfg`. CI starts clean.
- **`wait` counts seconds, and a smoke run quits at its limit.** Adding steps to `SAGE_SMOKE_COMMANDS` means
  raising the run's seconds (the render check is now 10 s on Linux and 12 s in the drawing job), or the later
  checks never run and the "all specs ran" count fails.
- **An OpenGL effect's constants follow the buffer's order, not the HLSL's.** With arrays and matrices in one
  effect, compare MonoGame's offsets with the GLSL's `ps_c` uses (the #592 diagnosis); `check_glsl_constants.py`
  only finds gaps.
- **A power cut can corrupt the clone.** One at 08:28 on 2026-10-30 left `.git/HEAD` and a branch's reflog all NUL
  bytes; both were restored by hand and `git fsck` came back clean. If git says "not a git repository", look at
  `.git/HEAD` first. A session's background watchers die with the machine too.
- **Check a new branch's upstream before a bare `git push`.** A branch made from `origin/main` can track it.
- **Merge `origin/main`, not a stale local `main`.** After merging a PR on GitHub, `git fetch` before merging
  `main` into the next branch.
- **Two PRs appending to `PublicAPI.Unshipped.txt` conflict.** Keep both sides, and keep the file's CRLF endings.
- **Long inline scripts in a shell command can lose backslashes.** Write a script to a file and run it instead.
- **New records in a test game change `schemas/ids.schema.json`.** The `foggy` sky failed
  `TheCommittedSchemas_AreWhatSageSchemaWrites`; its error message's `sage schema` list is short, so use `CLAUDE.md`'s.
- **`check_docs.py --fix` walks `.claude/worktrees/` too.** It rewrites counts in agents' worktrees: move them out
  (`git worktree move`) before a fix, or revert their count lines after. A stray `games/Hello/imgui.ini` also
  makes it count five files there; CI sees four.
- **A free camera reads the live mouse.** Two screenshots of one `cam_set` can differ for that alone, and
  `m_sensitivity` stops at 0.01 (0 is refused). `in_look` turns a first-person view from a script; it needs the clock
  running, so stop `time_scale` after it. Compare a frame with two frames of one mode first: a stopped clock doesn't
  stop the sky or particles.
- **Saves cover public members only.** An `internal` field on a component is silently not saved.
- **A screenshot is taken at the end of the frame,** after the next scripted command has run: put `+wait 0.5`
  after every `+screenshot`.
