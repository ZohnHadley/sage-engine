## 5. Traps

- **Cooked meshes went to format 4 (#363).** An older `.sgmesh` is refused with a warning and the loose `.glb`
  is read until you cook again; a game that ships only cooked meshes must re-cook.
- **Root motion reaches a character controller one tick late.** The animator extracts it in Phase.Animation; the
  controller takes it in the next tick's PrePhysics. A test that counts metres allows a tick
  (`ACharacterControllerWalksTheClipsDistance`).
- **Do not feed a root-motion blend from `from: Speed`.** The speed is what the clip produces, so the blend
  chases itself; drive it from intent (`MoveX`/`MoveY`) or from code.
- **`AttackStances.Set` is false without the component.** Give fighters `sage:attack_stance` in the prefab; no
  system adds it mid-tick.
- **A transition's `fade` is anim_graph-only.** `StateTransition` is shared with `state_machine`, which ignores
  the new fields; the schema shows them on both.
- **#362's branch merged `main` five times** while the other seven landed; the docs branch was cut from it, so
  it holds #362's code until PR #533 merges.
