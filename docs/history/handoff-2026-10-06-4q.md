## 5. Traps

- **Waiting on another verify with `pgrep -f` can match itself.** `pgrep -f 'vpush.sh 3'` matches the waiters' own
  command lines and two waiters deadlock. Use a bracket regex (`'vpush[.]sh 3(45|53)'`) or one sequential queue.
- **The smoke run fails on any WARN, and a paused world makes one.** A Fixed-phase event reader does not run while
  the world is paused (the title screen, a pause menu), falls behind, and the log says "Dropping ... slowest
  reader". A system that reads UI or sound events while paused needs `RunCondition.Always` (the `SubtitleSystem`
  fix in #351).
- **Measure text with `EffectiveTextScale`.** After #351, `TextScale` is the node's own; what is drawn is scaled
  by `ui_text_scale` too, and a measurement that uses the raw value is wrong at any setting but 1.
- **`Localisation.Languages(vfs)` is now `LanguagesIn(vfs)`**, beside the instance `Languages` property #339 added.
- **Frame goldens are taken without shaders, and Windows runs only the plan goldens.** `kit_screens_check.sh`
  runs the real client under Xvfb with `-p:SageSkipShaders=true` builds; a change that only shows with shaders on is
  not caught.
- **A new kit screen is a line in `tests/games/kit-screens/screens.txt` plus its goldens.** `EveryKitScreenIsInTheList`
  fails otherwise. Regenerate with `SAGE_UPDATE_GOLDENS=1 dotnet test tests/Sage.Tests -c Debug --filter
  KitScreenGoldenTests` and `tools/kit_screens_check.sh <host> --update`, then read the diff.
- **Merge order mattered.** #348 and #349 both edited the Sandbox's map; #349 merged second and removed #348's view
  (§2). When two issues touch the same layout, the second rebases on the first and says what it dropped.
