## 5. Traps

- **OpenGL drops the constants a shader does not use, and MonoGame fills them by register.** MojoShader packs the
  used constant registers of a shader into one array; MonoGame sets each parameter at its register. A parameter
  used only in part — a matrix whose last column the shader never reads — leaves a gap, and every constant after
  it is read from the wrong place: the sun's shadow matrices shifted the pixel shader's colours and fog by two
  registers and the ground drew black (#481). Read every column (`common.fxh` divides by `clip.w` for that).
  `tools/check_glsl_constants.py` fails on a gap, and the `drawing` CI job runs it on the compiled engine effects.
- **The same trap again, in any new shader parameter.** Pack 2 added `WetParams`, `LampShadow*` and `SoftParams`;
  each is read in full by the shaders that declare it. Run `tools/check_glsl_constants.py` after adding a parameter
  to `common.fxh` or a pixel shader that reads a new array.
- **The OpenGL build prints a shader's literals to six decimals.** `rsqrt(max(x, 1e-8))` became `rsqrt(x)`; keep
  literals at `1e-4` or larger, or pass a parameter (design 07 §3.8).
- **The `drawing` job** (`.github/workflows/ci.yml`) needs the Windows job's `engine-shaders` artifact, builds the
  Linux host, drops the `.mgfxo` files in and runs `tests/games/render-check` with `r_pixelcheck <spec> shaders`
  (shaders required, the Shaders log category not allowed). A shader change that compiles can still fail here; the
  Linux job runs the same scene without shaders (the clear-colour checks).
- **Measured tests and the GC:** a timing ratio in one test can be skewed by a collection of other tests' garbage;
  `SaveWriterMeasurements` collects first. Do the same in a new measured test.
- **Old cooked files are stale:** `.sgtex` without mips and `.sgmesh` before v3 are passed over with a warning and
  the loose file is read; re-run `sage cook` on a game cooked before the pack.
